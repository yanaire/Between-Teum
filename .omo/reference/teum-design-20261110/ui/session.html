M-01 모먼트 카드 · 변형

F1 변형은 우선 시안 8 보드에 있다. 구조는 같다: 어두워진 창, 가운데 틈 라이트, 그 빛 속에서 떠오르는 카드 (808, r48, 패딩 48, level3, 등장 900ms). 주 버튼 L 하나, 보조 M 둘. F2·F3처럼 보조가 셋이면 셋째는 Text button으로 무게를 더 낮춘다. 오전에 가면을 고른 날이라 빛은 '단호한 나'.

C-01 진행 프레임

세션 중에는 Page navigation을 숨긴다. 위에는 단계 점 (현재 = 빛, 폭 28)과 우상단 [끝내기] 하나. 아래 가장자리는 엣지 라이트 (남은 시간만큼 3px 선 + 12px 글로우). 가운데 영역만 단계별로 바뀌고, 바뀔 때는 크로스페이드 + 8px 상승 320ms. 엣지 라이트를 누르면 남은 시간을 토스트로 알려 준다.

C-02 끝내기 확인

System popup M (808, r48, 패딩 48, level3). 뒤의 세션은 일시정지 (호흡도 멈춘다). 버튼은 Horizontal 두 개. 주 버튼 대신 Pleos filled로 [끝내기]를 구분하고, [계속하기]는 basic. 바깥을 누르면 계속하기.

C-03 복귀 시퀀스

세션 시작 때 저장해 둔 시트·조명·공조 값으로 되돌린다. 항목이 0.4초 간격으로 차례로 켜지고, 끝난 항목은 informative/active 체크. 등받이가 움직이는 동안에만 [멈춤]. 창문을 열었던 세션이면 창문 항목이 하나 더 붙는다. 5~10초 뒤 자동으로 C-04. 화면 버튼은 없다 (자동 단계).

C-04 스탬프 토스트 · T-01 안내 토스트

둘 다 Toast popup (최대 792, 패딩 24 × 40, r16, 아이콘 48, 하단·좌우 24), 3초. C-04는 스탬프 아이콘이 찍히는 마이크로 모션 하나 (scale 1.2 → 1, 240ms, ease-out. reduced-motion이면 opacity만). [끝내기]로 끝난 세션에는 C-04가 없다. T-01은 같은 자리에서 '왜 건너뛰는지'를 한 줄로 말하고 다음 단계로 넘어간다.
