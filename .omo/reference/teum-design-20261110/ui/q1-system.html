Q1-01 3분 리셋 · 바로 시작

예고 없이 터진 스트레스 때 (예: 질책받은 직후). 홈에서 열고 모먼트 카드 없이 바로 시작한다. 3초 카운트 동안 차는 시트·조명·공조를 저장하고 앰비언트를 딥 블루 저조도로 바꾼다. 이어서 F1-03 호흡 컴포넌트를 그대로 쓴다 (2분, 진정 호흡). 화면 빛은 문라이트 — 딥 블루는 캐빈에만.

Q1-02 한 단어

호흡이 끝나면 마음을 한 단어로. 칩 넷 (Chip, Toggle S 64) 또는 말로. 고르면 바로 C-03 → C-04 '리셋 완료' → H-01. 기록은 하루 상세 (R-02)에만 남는다.

I-01 기어 이탈

세션 중에 기어가 P를 벗어나면 예외 없이 전체 화면을 즉시 닫고 H-02로 간다 (200ms 페이드). 차는 시트 이동을 즉시 멈추고 조명과 공조를 바로 되돌린다. 화면에서는 아무것도 묻지 않고 음성으로만 알린다. 다음 정차 때 I-03.

I-02 문 열림

세션 중에 문이 열리면 조명과 소리를 멈추고 묻는다. 30초 안에 닫히면 저절로 이어지고, 30초가 지나면 C-03. 남은 시간은 Pleos 로더 대신 줄어드는 숫자 하나로. 이어 가는 쪽을 Pleos filled로 구분.

I-03 중단된 세션 뒤

기어 이탈이나 시동 꺼짐으로 세션이 끊긴 뒤 다음 정차나 시동 때 한 번. 지금 차가 어떤 상태로 남아 있는지 숫자로 말한다. [등받이 원위치] → C-03, [그대로 둘게요] → H-01.
