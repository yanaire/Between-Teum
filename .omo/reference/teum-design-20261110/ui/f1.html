F1-01 어제의 나 (조건부)

전날 저녁 F4-05a에 남긴 말이 있을 때만. 편지 카드 (MaruBuri)가 곧 자막이고, 녹음이 재생되는 위치까지 파형이 빛으로 찬다. 재생이 끝나면 자동으로 F1-02. 넘기는 길은 [건너뛰기] 하나.

F1-02 체크인

큰 선택 카드 셋 (ChoiceCard, 최소 160, r32). 고르면 바로 F1-03으로 넘어가므로 주 버튼이 없다. 고른 마음에 따라 호흡이 달라진다는 것을 카드 아래 한 줄로 미리 알려 준다. 선택 카드 화면은 틈 위에 겹쳐 가운데 정렬. 이때 차는 등받이를 5° 젖히고 앰비언트를 따뜻한 저조도로 바꾼다 (아래 작은 진행 표시).

F1-03a 눈 감고 모드

F1-03 호흡에서 [눈 감고 하기]. 화면은 최소 밝기, 틈 라이트는 1px 선으로만 남고 숨은 실내 앰비언트와 소리가 이끈다. 화면 어디를 눌러도 F1-03으로 돌아간다. 시간이 끝나면 자동으로 F1-04.

F1-04 오늘의 한 가지

큰 마이크 (지름 160)가 주 버튼 역할. 듣는 동안 바깥 링이 소리 크기에 반응하고, 받아쓰기가 실시간으로 쌓인다 (확정 = primary, 중간 결과 = tertiary). 어제 이월된 일은 추천 칩으로. 마이크가 켜지면 앰비언트가 살짝 밝아진다.

F1-04a 다짐 확인

받아쓴 문장을 MaruBuri로 크게. 끝맺음은 '~하기'로 다듬어 보여 준다. 주 버튼 [맞아요], 보조 [다시 말하기].

F1-06 오늘의 카드

한 장짜리 카드: 날짜, 가면 이름과 색, 다짐 (MaruBuri 대형). 카드 오른쪽 끝에서 그날의 가면 빛이 새어 나온다. 음성이 카드를 한 번 읽어 준다. 차는 아침빛 (쿨 화이트)으로 밝히고 등받이 원위치, 외기 유입, 1℃ 낮춤, 열선 끔. [다녀오기] → C-03 → C-04 '준비 완료 · 연속 4일'.
