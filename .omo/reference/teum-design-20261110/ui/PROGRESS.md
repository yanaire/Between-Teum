## 결정 사항

- **산출물 형식**: 빌드 없는 정적 HTML 디자인 보드. `ui/index.html`에서 모든 보드로 이동한다.
- **공통 파일**: `ui/tokens.css` (handoff 원본 복사, 수정 금지), `ui/teum.css` (Pleos 컴포넌트 + 틈틈 브랜드 + 보드 레이아웃), `ui/teum.js` (보드 줌, 아이콘, 호흡 데모).
- **화면 하나** = `<article class="frame" data-screen="ID" data-o="p|l" data-theme="dark" data-mask="firm">`. 보드에서는 `<figure class="shot">`로 감싸고 캡션에 ID·이름·메모.
- **폰트**: Asta Sans, Manrope, Gowun Batang (Google Fonts), MaruBuri (Naver CDN, 실패 시 Gowun Batang).
- **아이콘**: Lucide (unpkg, 라운드 라인, stroke 1.75) — 48 그리드 라운드 라인 세트 대용. 텍스트 라벨과 함께.
- **색**: 헥스 직접 사용 금지. `--pleos-*`, `--teum-*`, `--light-current`만 쓴다. 보드 캔버스(앱 밖)만 예외.
- **주의**: `--teum-*` 별칭은 `:root`에서 계산되므로 `[data-theme]` 요소에서 다시 선언해야 라이트 테마가 먹는다 (teum.css에서 처리).
- **오늘의 페르소나 데이터**: 11월 13일 목요일 (주간 수치와 맞추려고 PRD 예시의 10일 월요일에서 바꿈), 가면 '단호한 나'(firm), 다짐 "기획안 초안 끝내기", 점심 리차지 20분, 16:00 A사 신제품 제안 미팅.
- **모션** (emil-design-eng 반영): 눌림 scale .97, scale(0) 금지, transform·opacity만, 퇴장이 등장보다 빠름, stagger 30–80ms, reduced-motion 시 위치·크기 모션 끔. 디자인 시스템 토큰(dur.*, ease.*)이 우선.

## 미리보기와 점검 방법

- 서버: 프로젝트 루트 `.claude/launch.json`의 `teum-ui` (= `node ui/serve.mjs`, http://localhost:5179). 사용자는 Chrome에서 `ui/index.html`을 바로 열어도 된다.
- 내장 브라우저 창이 가려져 있으면 스크린샷이 시간 초과된다. 그때는 `ui/tools/shot.ps1`(헤드리스 Edge)로 찍고 Read로 본다. `?f=ID`는 그 화면만, `?z=0.62`는 배율.
- 배운 것: `filter: blur`와 `mask-image`를 한 요소에 같이 걸면 블러가 상자에서 잘려 사각형이 된다. 틈 glow는 radial-gradient 타원으로 그린다 (teum.css에 반영됨).
- impeccable hook의 'numbered-section-markers' 경고는 화면 ID(H-01 등) 때문에 뜨는 오탐이다. 화면 ID는 규칙상 유지한다.
