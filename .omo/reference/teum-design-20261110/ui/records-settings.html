R-01 이번 주

기록과 설정은 정차 중에만 열린다. Page navigation Depth (뒤로 56 + 제목), Suffix [보관함]. 히어로 숫자는 '되찾은 시간' (틈에 쓴 분 합계) 하나. 월~일 7칸 스탬프는 칸마다 그날의 하루 색과 채운 틈 개수. 숫자에는 강조색을 쓰지 않는다 — 자랑이 아니라 기록. 날짜 칸 → R-02.

R-02 하루 상세 · R-03 보관함

R-02: 그날의 틈 타임라인, 다짐과 결과, 가면, 하루 색, 미팅 메모 (F3-08). R-03: '내일 다시 보기' 메모 (F4-04a)와 '내일의 나에게' 메시지 (F4-05a). 항목마다 [삭제] (S 64). 털어내기 내용은 설정의 보관 기간이 지나면 저절로 지워진다.

ST 설정

설정 첫 화면은 Vehicle settings list (항목 112, 아이콘 컨테이너 80, r32). 각 항목이 ST-01 ~ ST-08. 켜고 끄는 것은 Switch M (폭 80). Landscape는 왼쪽 목록 + 오른쪽 상세 (Pleos 설정 앱과 같은 2단).
