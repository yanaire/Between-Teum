```
틈틈
├── 온보딩 (최초 1회)

│       → ON-06 휴식 자세 → ON-07 소리·음성 → ON-08 완료

├── 홈 ─────────────── [Page navigation Main]
│   ├── H-01 홈 (정차)
│   ├── H-02 주행 중 화면 (터치 없음)
│   └── H-03 세션 컴팩트 뷰 (다른 앱과 1:1일 때)
```

## 2. 화면 ID 규칙

- **영역 접두어 + 두 자리 번호**: `ON-01`, `H-01`, `F1-03`, `R-02`, `ST-05`, `I-01`
- **같은 화면 안의 팝업, 오버레이, 하위 모드**는 소문자를 붙인다: `F1-03a` (눈 감고 모드), `F2-01a` (시간 바꾸기 팝업)
- **`V-01`**은 화면이 없는 음성 전용 장면이다. 프로토타입에서는 음성 자막 바로만 보여 준다.
- **M-01 변형**: `F2-01`, `F3-01`, `F4-01`은 `M-01` 컴포넌트에 `variant` prop만 바꿔 만든다.
- **코드 규칙**:
  - 파일: `screens/<ID>-<PascalName>.tsx`
  - 라우트: `/s/<ID>`
  - 테스트 셀렉터: `data-screen="<ID>"`

## 3. 내비게이션과 레이아웃 모드

### 3-1. Pleos 창 정책 (공식 문서·Figma 원본 기준)

자세한 값은 `07-PLEOS-FOUNDATION.md` §2~3에 있다.

- **Connect-S 17인치** (기본, 2560 × 1440, 160dpi): 앱 하나면 2:0, 둘이면 1:1이다. 기본값은 1:1이다.
- **Connect-W**: 2:1 또는 1:2이다. 기본값은 2:1이다. 어느 경우든 한 번에 최대 두 개의 앱이 보인다.
- **Activity 기본 방향은 portrait다.** `screenOrientation`을 landscape로 지정하면 두 창을 합쳐 쓴다.
- **Pleos 설계 원칙**: Portrait에서 핵심 기능을 완결하고, Landscape에서 부가 정보와 확장 기능을 더한다.
- 상태바 (96), GNB (160), 키보드는 앱 창 위 레이어라 앱을 잠시 가릴 수 있다. 앱 창 모서리는 라디우스 40으로 잘린다.

### 3-2. 틈틈의 레이아웃 모드

| 모드 | 언제 | Connect-S 크기 | 규칙 |
|---|---|---|---|
| **Portrait** (기본) | 1:1 분할의 한 창. 앱을 처음 열 때 | 840 × 1184 | **모든 화면의 핵심을 여기서 완결한다.** 1단. 좌우 여백 40. 상단에 Page navigation (80) |
| **Landscape** (확장) | 앱 하나가 앱 영역 전체를 쓸 때 | 1700 × 1184 | 같은 화면에 부가 정보를 더한다. H-01은 오른쪽 열에 주간 기록, 세션은 틈 라이트 양옆으로 빛이 번지는 여백, F4-03은 타임라인과 질문을 좌우 2단으로 |

- 다른 폼팩터는 같은 레이아웃을 스케일한다. S14는 672 / 1360 × 948, L은 628 / 1274 × 855, W는 800 / 1640 × 810이다.
- 레이아웃은 px 고정이 아니라 container query로 짠다. 앱 창 폭 1200 이상이면 Landscape다.
- **세션 연출 권장**: M-01이 뜨거나 세션이 시작될 때 앱이 Portrait로 떠 있다면 [크게 보기]를 제안한다. 이 버튼은 Landscape로 전환한다 (window 버튼 동작). 강제로 전환하지는 않는다.

### 3-3. 전역 내비게이션 (Pleos Page navigation)

- **H-01**: Page navigation **Main**.
  - 왼쪽: 앱 아이콘 (80, 라디우스 20)과 "틈틈"
  - 오른쪽 Suffix: Icon button [기록], [설정]
- **R, ST**: Page navigation **Depth**. 뒤로 아이콘과 화면 제목.
- **세션 중**: Page navigation을 숨긴다. 빠져나가는 길은 우상단 Text button [끝내기] 하나다.
- **주행 중 (`H-02`)**: 내비게이션이 없다.
- 왼쪽 레일과 하단 탭은 쓰지 않는다. Pleos 기본 앱의 상단 내비게이션 패턴과 맞추기 위해서다.
