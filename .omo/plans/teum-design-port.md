## 확정한 이식 구조와 순서

원본 HTML/CSS/SVG를 오프라인 WebView 앱 창에 유지한다. 네이티브 코드는
세션·기록·권한·음성/소리·위치·차량 안전의 실제 상태를 소유한다.
출처·메인 프레임·허용 액션·현재 세션을 검사하는 메시지 연결만 허용한다.

1. 기존 controller의 세션 orchestration을 coordinator로 분리하고 기존
   네이티브 회귀 계약을 유지한다. st_01a1c5d6, 확인 모델 GPT-6.1 Sol.
2. 부모는 원본 CSS/SVG/토큰·글꼴·아이콘을 오프라인 자산으로 이식하고
   실제 브라우저로 원본과 비교한다. coordinator와 파일 소유권이 다르다.
3. 분리된 상태/액션 계약을 직접 검수한 뒤 WebView host 및 원본 화면의
   실제 상태 투영을 연결한다. MainActivity·Gradle·Manifest는 부모만 변경한다.
4. 저장/음성/소리/제안은 고정된 계약과 분리된 파일 범위로 구현한다.
   제품 화면의 공유 screens.js 및 최종 통합은 부모가 직렬로 소유한다.
5. 한 기기 소유자가 실제 앱 시나리오와 전체 회귀를 검증한다.
