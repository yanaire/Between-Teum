# Pleos Connect project

For Pleos feature requests in this repository, load `.agents/skills/pleos-connect-sdk/SKILL.md` before selecting SDK APIs or changing application code.

The skill maps natural-language feature requests to the documented SDK surface, permission/capability checks, lifecycle handling and emulator verification. It does not turn ordinary development instructions into a request for app voice input.

Preserve unrelated changes. For questions or document-only requests, do not change app code.
